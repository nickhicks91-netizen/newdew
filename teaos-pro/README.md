
## 🔧 Ollama Integration

### Setup Ollama (Optional)

1. **Install Ollama**: Download from [ollama.ai](https://ollama.ai)

2. **Pull a model**:
```bash
ollama pull llama2
# or
ollama pull mistral
```

3. **Start Ollama**:
```bash
ollama serve
```

4. **Configure in TeaOS PRO**:
   - Click "Settings" in the top right
   - Toggle "Enable Ollama"
   - Set endpoint (default: `http://localhost:11434`)
   - Choose your model
   - Click "Apply"

### Without Ollama

The app works perfectly in **Local Mode** without Ollama:
- Structured geometric responses
- Full memory architecture active
- All metrics and visualizations functional
- Baseline comparison operational
